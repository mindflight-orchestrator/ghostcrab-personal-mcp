# GhostCrab MCP Tools Reference

> Generated by `node scripts/export-operator-catalog.mjs` from the compiled MCP registry. Do not hand-edit tool entries.

GhostCrab exposes 62 registered MCP tools, all returned by MCP `tools/list` and directly callable by name. A curated subset of 13 is flagged as recommended defaults (`title: GhostCrab recommended default`); the other 49 are extended tools. Use `gcp tools list`, `gcp tools verify`, and `ghostcrab_tool_search` for discovery metadata and domain filtering.

All successful tool calls use the additive envelope:

```json
{
  "ok": true,
  "tool": "ghostcrab_status",
  "surface_version": "2026-03-23",
  "generated_at": "2026-03-23T08:00:00.000Z"
}
```

Tool-specific fields are added next to that envelope. Structured failures use the same envelope with `ok: false` and `error.code`.

### `ghostcrab_graph_gap_rules_import`

Write. Import closed-world gap rules: unary cardinality checks per entity_type and relation_type (e.g. each unit must have exactly one assigned_cellar). Then list via ghostcrab_graph_gap_rules and validate via ghostcrab_graph_diagnostics. Accepts the full gap-rules JSON envelope (ontology_id, workspace_id, replace, rules).

| Field | Value |
|-------|-------|
| Visibility | extended |
| Subsystem | graph |
| Access | write |
| Required arguments | `ontology_id`, `rules` |

| Argument | Required | Type | Description |
|----------|----------|------|-------------|
| `ontology_id` | yes | `string` | Ontology id the rules belong to. Example: immeuble-demo::core. |
